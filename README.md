# TunaLab

A research framework for machine learning experiments.

## Projects Using TunaLab

- [nanoGPT](https://github.com/evintunador/nanoGPT) - A minimalist implementation of GPT for training and fine-tuning language models
- [tagseq2tagseq](https://github.com/evintunador/tagseq2tagseq) - Text-Attributed Graph Sequence-to-Text-Attributed Graph Sequence modeling experiments
